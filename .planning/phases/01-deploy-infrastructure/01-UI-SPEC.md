## Interaction Contracts

### Error Boundary
| Property | Contract |
|----------|----------|
| **Type** | Class component (`Component` base) — React 19 requires class for error boundaries |
| **Placement** | Wraps `<Routes>` inside `<BrowserRouter>` (so `useLocation()` is accessible) |
| **Reset mechanism** | `key={location.pathname}` — new instance on every route change |
| **Fallback UI** | Centered flex column: `AlertTriangle` icon (48px) → "Noget gik galt" heading → error message → "Prøv igen" Button |
| **Styling** | Uses existing dark theme tokens: `text-muted-foreground`, `bg-secondary`, `text-xl font-semibold` |
| **Retry behavior** | `setState({ error: null })` resets boundary, children remount |
| **Side effects** | `componentDidCatch` logs to console — no toast, no Sentry (per D-08) |
| **D-Ref** | D-06, D-07, D-08 |

### Loading States (Skeletons)
| Property | Contract |
|----------|----------|
| **Animation** | Tailwind v4 `animate-pulse` utility — 2s cubic-bezier opacity pulse |
| **Placement** | Per-page conditional: `if (loading) return <PageSkeleton />` |
| **Affected pages** | Dashboard, ListsHome, ListDetail, Pantry |
| **Not affected** | Scanner (no Firestore data), Settings (no Firestore data), AuthPage (uses spinner) |
| **Hook loading sources** | `useLists(user?.uid).loading`, `useDocument(path).loading`, `useListItems(id).loading`, `usePantry(user?.uid).loading` |
| **Skeleton markup** | Per-page custom `div` layout using `animate-pulse` + `bg-secondary` rounded blocks that mirror data layout |
| **Shared component** | NOT used — per D-11, each page has its own skeleton function |
| **Auth gate loading** | Existing spinner in `App.tsx:14-20` — no change needed |
| **D-Ref** | D-09, D-10, D-11 |
