### Task 02: Configure Vitest in vite.config.ts

<read_first>
- `vite.config.ts` (current config — add `test` block)
</read_first>

<action>
Add `/// <reference types="vitest" />` at the top of `vite.config.ts` and a `test` config block inside `defineConfig`:

```typescript
/// <reference types="vitest" />
import { defineConfig } from 'vite'
// ... existing imports ...

export default defineConfig({
  // ... existing config ...
  test: {
    environment: 'happy-dom',
    setupFiles: [],
    globals: true,
  },
})
```

Do NOT remove any existing config. Just add the `test` section alongside existing keys.
</action>

<acceptance_criteria>
- `vite.config.ts` opens with `/// <reference types="vitest" />`
- `vite.config.ts` has a `test` key with `environment: 'happy-dom'`
- `vite.config.ts` has `globals: true` in the test config
</acceptance_criteria>

### Task 04: Write smoke tests

<read_first>
- `src/lib/utils.ts` (existing utility — write a test for `cn()`)
- `src/App.tsx` (existing component — write a basic render test)
</read_first>

<action>
Create `src/__tests__/utils.test.ts`:

```typescript
import { describe, it, expect } from 'vitest'
import { cn } from '../lib/utils'

describe('cn', () => {
  it('merges class names', () => {
    expect(cn('foo', 'bar')).toBe('foo bar')
  })

  it('handles conditional classes', () => {
    expect(cn('base', false && 'hidden', 'visible')).toBe('base visible')
  })
})
```

Create `src/__tests__/App.test.tsx`:

```typescript
import { describe, it, expect } from 'vitest'
import { render, screen } from '@testing-library/react'
import App from '../App'

describe('App', () => {
  it('renders without crashing', () => {
    // This is a basic smoke test — App wraps BrowserRouter only when user is null,
    // so we just verify it renders something
    render(<App />)
    expect(screen.getByText(/groc/i)).toBeTruthy()
  })
})
```

Note: Tests may need adjustments if the component renders async or conditionally. The goal is a passing smoke test, not comprehensive coverage.
</action>

<acceptance_criteria>
- `src/__tests__/utils.test.ts` exists and contains tests for `cn()`
- `src/__tests__/App.test.tsx` exists and contains a render test for `App`
- `npm test` exits with code 0 (all tests pass)
</acceptance_criteria>
