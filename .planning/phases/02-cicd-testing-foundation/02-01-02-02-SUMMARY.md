Single workflow file with 4 sequential jobs:
- **lint**: `actions/checkout@v4` → `setup-node@v4` (Node 20, npm cache) → `npm ci` → `npm run lint`
- **test** (needs: lint): checkout → setup-node → npm ci → `npm test`
- **build** (needs: test): checkout → setup-node → npm ci → `npm run build`
- **deploy** (needs: build, if push to main): checkout → setup-node → npm ci → `npx vercel deploy --prod`

Triggers: `push` and `pull_request` on `main`. Deploy job only runs on push to main.
