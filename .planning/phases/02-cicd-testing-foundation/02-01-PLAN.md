# Plan 02-01: GitHub Actions CI/CD Pipeline

## Objective

Create a GitHub Actions workflow that runs lint, test, and build on every push and PR to `main`, then deploys to Vercel on push to `main` if all checks pass.

## Tasks

### Task 01: Create CI workflow file

<read_first>
- `.planning/phases/01-deploy-infrastructure/01-CONTEXT.md` §Vercel Setup (D-03: GitHub already connected)
</read_first>

<action>
Create `.github/workflows/ci.yml` with:

1. **Trigger:** `push` and `pull_request` on `main` branch
2. **Environment:** `ubuntu-latest`, Node 20
3. **Caching:** `actions/setup-node` with `cache: 'npm'`
4. **Jobs (sequential):**
   - `lint`: runs `npm run lint` (ESLint)
   - `test`: runs `npm test` (Vitest)
   - `build`: runs `npm run build` (tsc + vite build)
   - `deploy`: runs only on `push` to `main`, depends on `build`
5. **Deploy job:** Use Vercel's existing git integration (already connected in Phase 1 D-03). The deploy job should use `vercel-deploy-action` or the Vercel CLI via `npx vercel deploy --prod --token=${{ secrets.VERCEL_TOKEN }}`
   - Add `VERCEL_TOKEN` to repository secrets in GitHub
   - Add `VERCEL_ORG_ID` and `VERCEL_PROJECT_ID` from `.vercel/project.json` to repo secrets or workflow env

Workflow file structure:
```yaml
name: CI/CD
on:
  push:
    branches: [main]
  pull_request:
    branches: [main]

concurrency:
  group: ${{ github.workflow }}-${{ github.ref }}
  cancel-in-progress: true

env:
  VERCEL_ORG_ID: ${{ secrets.VERCEL_ORG_ID }}
  VERCEL_PROJECT_ID: ${{ secrets.VERCEL_PROJECT_ID }}

jobs:
  lint:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: 20
          cache: 'npm'
      - run: npm ci
      - run: npm run lint

  test:
    needs: lint
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: 20
          cache: 'npm'
      - run: npm ci
      - run: npm test

  build:
    needs: test
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: 20
          cache: 'npm'
      - run: npm ci
      - run: npm run build

  deploy:
    needs: build
    if: github.event_name == 'push' && github.ref == 'refs/heads/main'
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: 20
          cache: 'npm'
      - run: npm ci
      - run: npx vercel deploy --prod --token=${{ secrets.VERCEL_TOKEN }}
```
</action>

<acceptance_criteria>
- `.github/workflows/ci.yml` exists
- File contains `on:` with `push` and `pull_request` triggers for `main`
- File contains `lint`, `test`, `build`, and `deploy` jobs
- `deploy` job has `if: github.event_name == 'push' && github.ref == 'refs/heads/main'`
- `deploy` job uses `needs: build`
- Each job uses `node-version: 20` and `cache: 'npm'`
</acceptance_criteria>
